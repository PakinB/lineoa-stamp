# ไฟล์ภาพของร้าน

วางไฟล์ที่นี่แล้วเรียกใช้ในโค้ดด้วย path ที่ขึ้นต้นด้วย `/` เช่น `/stamp/on.svg`

```
public/
  stamp/     ภาพดวงสแตมป์
    on.svg     ดวงที่ปั๊มแล้ว
    off.svg    ดวงว่าง
    cp.svg     ดวงที่มีรางวัล (ช่อง 6, 8, 10)
  brand/     โลโก้ พื้นหลัง ภาพของรางวัล
```

รองรับ `.svg` `.png` `.jpg` `.webp` — **แนะนำ SVG** เพราะคมทุกขนาดหน้าจอ
และเปลี่ยนสีจาก CSS ได้ ถ้าเป็น PNG ให้ส่งมาที่ความละเอียดอย่างน้อย
3 เท่าของขนาดที่แสดงจริง (ดวงกว้าง 62px บนจอ = ไฟล์ควรกว้าง ~190px)
